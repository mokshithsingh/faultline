Faultline Demo App

Interactive sandbox to test the Faultline plain JavaScript SDK.

Target: https://faultline-dashboard-mvak.onrender.com

1. Uncaught Runtime Error

Triggers a global window.onerror by accessing a property on undefined.

2. Unhandled Rejection

Triggers an async rejection caught automatically by window.onunhandledrejection.

3. Manual Exception

Catches a JSON parse failure and calls Faultline.captureException(err).

4. Custom Fingerprint

Dispatches an error with an explicit fingerprint override for custom grouping.

5. Diagnostic Message

Captures an operational message using Faultline.captureMessage(msg).
